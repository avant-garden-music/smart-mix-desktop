# Smart Mix font licenses

The Brand Identity v1 uses only redistributable open-source fonts already bundled with Smart Mix.

All listed families are distributed under the SIL Open Font License 1.1. The complete license text is stored in `OFL-1.1.txt` in this directory.

| Family | Smart Mix role | Upstream project |
|---|---|---|
| Sora | Wordmark, headings and primary text | https://github.com/sora-xor/sora-font |
| Barlow Semi Condensed | UI, navigation, buttons and tables | https://github.com/jpt/barlow |
| Big Shoulders Display | Editorial display typography | https://github.com/xotypeco/big_shoulders |
| Dela Gothic One | Limited identity accents | https://github.com/syakuzen/DelaGothic |
| JetBrains Mono | BPM, LUFS, duration and numeric data | https://github.com/JetBrains/JetBrainsMono |

The exported wordmark and logo lockups use Sora 700 converted to vector outlines. The outlined SVGs do not require the font at render time; the editable Penpot source retains Sora text for future approved revisions.

Do not rename or modify the bundled fonts without rechecking Reserved Font Name requirements under OFL 1.1.
